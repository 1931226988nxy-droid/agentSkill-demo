# 图表与统计

- 沿用已有 Vue 图表库或封装，Ant Design Vue 不等于已安装图表引擎。无需求不新增依赖。
- 趋势用折线，类别比较用柱状/条形，构成只在分类较少时使用环图。
- 图表系列使用主题的 --chart-* 变量，同一指标保持固定语义，不让渐变顶栏颜色决定所有数据颜色。
- 网格线轻、轴文字清晰，字号保持与业务页一致；图表标题前可使用短蓝色标记。
- 显示数据来源、时间范围和单位。未知值、缺失和零区分，不使用虚构曲线填空。
- 数量比较柱状图通常从零开始；轴范围不得误导。
- 不只依赖颜色/悬停，提供文字摘要或数据表。
- 响应容器变化；读取系统减少动画偏好；加载、空数据和失败提供对应状态。

可调整：图表库、配色、数字格式、动画和摘要方式。
本次模板展示工作台和树表管理，没有附加新的图表库。
